02 / Erklärungen

Die wichtigsten Themen

Lies die Erklärung und achte besonders darauf, welche Aufgabe der jeweilige Baustein übernimmt.

Infrastructure as a Service

IaaS

Was ist das? Ein Cloud-Anbieter stellt grundlegende IT-Infrastruktur über das Netzwerk bereit. Dazu gehören virtuelle Server, Speicher und Netzwerke.

Dein Vorteil: Ressourcen können flexibel skaliert werden. Du musst keine eigene physische Serverhardware betreiben.

Merke: Beim IaaS-Modell verwaltest du typischerweise Betriebssystem, Anwendungen und Daten. Der Anbieter betreibt die zugrunde liegende Hardware.

Virtual Machine

VM

Was ist das? Eine VM ist ein isolierter, softwarebasierter Rechner. Sie erhält virtuelle CPU-, RAM- und Speicherressourcen und startet ein Betriebssystem.

Typische Einstellungen: Image, Instanzgrösse, Netzwerk, Speicher und Zugriffsschlüssel.

Merke: Ein Image ist die Vorlage für das Betriebssystem. Die VM ist die daraus gestartete Instanz.

SSH-Keypairs

Authentifizierung

Was ist das? Ein Keypair besteht aus einem privaten und einem öffentlichen Schlüssel. Der öffentliche Schlüssel kommt auf den Server, der private bleibt geheim bei dir.

Warum? Der Server kann prüfen, ob du den passenden privaten Schlüssel besitzt, ohne dass dieser übertragen wird.

Public Key → auf dem Server hinterlegen
Private Key → sicher und geheim aufbewahren

Cloud-Init

Konfiguration

Was ist das? Cloud-Init ist ein Werkzeug zur automatischen Initialisierung von Cloud-Instanzen. Es verarbeitet beim Start Konfigurationsdaten.

Beispiele: Benutzer anlegen, Pakete installieren, Dateien schreiben oder Dienste konfigurieren.

#cloud-config
package_update: true
packages:
- nginx
Merke: Cloud-Init automatisiert wiederkehrende Einrichtungsschritte und macht Starts reproduzierbarer.
